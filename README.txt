WISDOM WINGS ENGLISH MEDIUM SCHOOL – WEBSITE
=============================================

Open index.html in any browser to view the site.

TO PUT IT ONLINE
Upload everything in this folder (index.html, docs, img) to your web host's
public folder (usually "public_html" or "htdocs"). Keep the folder structure.

TO UPDATE INFORMATION
Open index.html in a text editor (Notepad, VS Code). Near the top, inside the
first <script> block, you will find the data sections:
  SCHOOL     – name, phones, email, address
  GENERAL    – Section A
  DOCUMENTS  – Section B (PDF links)
  ACADEMIC   – Section C
  STAFF / TEACHERS – Section D
  INFRA      – Section E
  FEES, TRUST, HOUSES, EVENTS, CALENDAR – other pages
To add a new PDF: put it in the "docs" folder and write its path, e.g.
  url: "docs/my-file.pdf"
